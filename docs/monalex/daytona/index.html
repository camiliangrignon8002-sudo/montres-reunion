À propos de ce modèle

Modèle 3D construit entièrement en code (géométrie paramétrique, matériaux PBR, textures générées). C'est une interprétation visuelle : il ne remplace ni une photo, ni un modèle CAO du fabricant.

MesureValeurSource

« officiel » : valeur publiée par Rolex pour la référence 126500LN. « estimé » : estimation de modélisation, réglable dans js/dims.js.

Le mouvement est une interprétation pédagogique inspirée du calibre 4131 (chronographe automatique, roue à colonnes, 4 Hz, 72 h). Ce n'est pas une copie certifiée : disposition, formes et nombres de dents sont plausibles, pas relevés sur pièce. Sur la vraie montre, le fond est en acier plein : le fond saphir du mode Technique sert seulement à montrer l'intérieur.
